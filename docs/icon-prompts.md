# Prompt ikon menu — Juragan Laundry

Ikon untuk dok menu bawah, dibuat tanpa teks atau label. Pakai di ChatGPT (gambar), Midjourney, Ideogram, atau ForgeGUI.

## Cara pakai

1. Gabungkan **Gaya dasar** dengan salah satu **Subjek** di bawah.
2. Buat satu per satu dengan gaya dasar yang sama supaya set-nya seragam. Kalau alatnya mendukung, unggah ikon pertama sebagai referensi gaya untuk ikon berikutnya.
3. Simpan sebagai PNG transparan 512×512, lalu beri nama sesuai kolom **File** (misalnya `assets/icons/bangun.png`). Game bisa diubah supaya memakai file ini menggantikan ikon garis yang sekarang.

## Gaya dasar (tempel di awal setiap prompt)

```
Game UI icon for a cozy laundry business tycoon game, single object centered, isometric three-quarter view,
soft rounded chunky shapes, clean thick outline in deep teal (#0b636a), flat colors with gentle cel shading,
palette: teal #0f7c83, soap white #f4fbfb, sunny yellow #ffc533, coral accent #ef5a45, light aqua #bfe7e4,
small highlight on the top-left, soft contact shadow underneath, transparent background, generous padding,
readable at 48 px, consistent icon set, mobile game style, 1024x1024
```

**Negative prompt / hindari:** `text, letters, numbers, words, watermark, logo, signature, photorealistic, busy background, scene, multiple scattered objects, people faces in detail, gradient noise`

## Tips konsistensi

- Kalau hasil masih memuat huruf, tambahkan `blank, unlabeled` ke subjek.
- Pertahankan sudut pandang dan tebal garis yang sama. Tolak hasil yang memakai sudut pandang berbeda.
- Untuk tampilan gelap, garis teal tua tetap terbaca. Tidak perlu versi kedua.
